# SolatTime – Prayer Assistant

## Overview

SolatTime is an Electron-based desktop application developed for the CSC2923 Object-Oriented Programming Final Project.

The application assists Muslim users in accessing accurate prayer times based on Malaysian JAKIM prayer zones. It combines prayer schedules, countdown timers, religious reminders, and daily spiritual activities into a single desktop application.

## Features

### 🕌 Prayer Time Retrieval
- Retrieve prayer times using the WaktuSolat API.
- Support prayer zone selection across Malaysia.
- Display daily prayer schedules accurately.

### ⏳ Prayer Countdown Timer
- Calculate the remaining time until the next prayer.
- Automatically update every second.
- Highlight the upcoming prayer.

### 📅 Monthly Prayer Timetable
- Display a complete monthly prayer timetable.
- Allow users to view prayer schedules for multiple days.

### 📖 Daily Doa & Zikr Checklist
- Interactive checklist for daily spiritual activities.
- Encourage users to maintain consistent religious practices.

### 🔔 Reminder Management System
- Create custom reminders.
- Edit existing reminders.
- Delete unwanted reminders.
- Enable or disable reminders.
- Configure repeat days for reminders.

### ⭐ Suggested Religious Activities
Users can quickly add recommended reminders such as:
- Read Surah Al-Kahf
- Morning Adhkar & Zikr
- Read Surah Al-Mulk
- Prepare Wudhu Before Adhan
- Tahajjud Prayer
- Sadaqah Reminder
